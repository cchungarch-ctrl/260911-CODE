# 第二章：核心業務模組規格

> **版本**：v1.0.0  
> **最後更新**：2026-09-11  
> **分類**：核心業務模組規格

---

## 2.1 專案切換與頂部狀態列 (`Header.tsx`, `Sidebar.tsx`)

### 功能規格
1. **專案多選切換**：
   - 支援切換多個預設工程：`PRJ-TEAM`（團隊總覽跨專案）、`PRJ-001`（信義 A11）、`PRJ-002`（南港車站）、`PRJ-003`（桃園高鐵）。
   - 切換專案時，自動過濾任務、甘特排程與 RFI 列表。
2. **快速操作**：
   - 「新增工作項目 (+ Task)」：開啟工作項目建立 Modal。
   - 「提出 RFI 申請 (+ RFI)」：開啟工程釋疑單建立 Modal。
   - 「匯出靜態單檔 HTML」：觸發 `generateHtml.ts` 產生自包含 HTML 並開啟原始碼/下載視窗。
   - 「重設範例資料」：清除 LocalStorage 並還原初始狀態。

---

## 2.2 工程甘特圖排程模組 (`GanttChart.tsx`)

### 功能規格
1. **時間軸檢視**：
   - 支援以「日」、「週」、「月」尺度檢視各工種排程區間。
   - 計算工期起訖日期、進度百分比（Progress %）、工種標籤（結構工程、建築設計、機電MEP、現場施工）。
2. **互動拖曳與縮放**：
   - 支援直覺滑鼠縮放與時間軸水平滾動。
   - 點擊甘特圖項目可直接檢視詳細任務資料與關聯 RFI。

---

## 2.3 敏捷工程工作看板 (`KanbanBoard.tsx`)

### 功能規格
1. **四象限工作流**：
   - `backlog`（待辦清單 / 待開工）
   - `in_progress`（施工中 / 進行中）
   - `review`（品檢查驗 / 審查中）
   - `done`（驗收完成 / 已完工）
2. **拖曳更新**：
   - 支援拖曳任務卡片在欄位間平滑移動，即時更新資料庫/LocalStorage 狀態。
3. **任務卡片詳細資訊**：
   - 顯示優先級標籤（`high` / `medium` / `low`）、專業分工、負責人頭像、到期日警示、現場照片縮圖。

---

## 2.4 RFI 資訊請求簽核與追蹤模組 (`RfiTracker.tsx`)

### 功能規格
1. **釋疑單狀態循環**：
   - `待處理` -> `審查中` -> `已回覆` / `已駁回`
2. **工程影響評估**：
   - 每張 RFI 包含「工期影響天數 (Impact Days)」與「預估影響成本 (Impact Cost NTD)」。
3. **結構化審查與簽核彈窗 (`ViewRfiModal.tsx`)**：
   - 建築師/技師可直接在彈窗內輸入工程指示回覆與上傳相關圖說佐證照片。
   - 自動將該 RFI 狀態變更為「已回覆」，並記錄回覆日期。

---

## 2.5 專案人員與角色管理 (`UsersView.tsx`)

### 功能規格
1. 呈現專案專用人員名冊：工地主任、結構技師、機電負責人、BIM 協調員等。
2. 統計各人員名下指派之待辦任務數與關聯 RFI 件數。

---

## 2.6 工務進度與數據分析 (`AnalyticsView.tsx`)

### 功能規格
1. **S-Curve 施工進度分析**：計畫進度 vs 實際進度對比。
2. **工種分佈比例**：結構、建築、機電與施工佔比環狀/長條圖。
3. **RFI 風險分析**：累計因 RFI 延誤之工期天數與總額外成本評估。

---

## 2.7 模擬 REST API 主控台 (`ApiConsole.tsx`)

### 功能規格
1. 提供 RESTful API 呼叫測試介面（支援 `GET`、`POST`、`PUT`、`DELETE`）。
2. 即時輸出 HTTP 狀態碼、Headers、Payload 與 Response JSON。
3. 自動記錄近 50 筆 API 操作日誌（包含時間戳記與專案 ID）。

---

## 2.8 獨立單檔 HTML 靜態匯出引擎 (`generateHtml.ts`)

### 功能規格
1. **零外部依賴打包**：直接將目前 LocalStorage 中的專案、任務、RFI 與人員狀態序列化，嵌入單一獨立 HTML 檔案。
2. **完全可離線執行**：輸出的 HTML 內嵌 Tailwind CSS CDN 與純 JavaScript 互動式看板，可直接以瀏覽器離線開啟運作。
3. **工時資料內嵌**：`WorkLog[]` 與 `UserRate[]` 一併序列化於 `STATE` 中，供離線環境完整還原工時模組資料。

---

## 2.9 工時計算與成本核算模組 (`WorkHoursView.tsx`)

### 功能規格
1. **工時填報區**：
   - 透過 `LogWorkHoursModal.tsx` 填報工時，欄位包含：關聯任務、填報人員、日期、正常工時、加班時數與工作摘要。
   - 前端驗證：工時須大於 0、單日上限 24 小時、加班須大於等於 0。
2. **人員工時統計面板**：
   - 依人員彙總工時、加班時數、工作量、正常成本、加班成本與總人工成本。
3. **工時成本核算**：
   - 成本 = 正常工時 × 時薪 + 加班時數 × 時薪 × 加班倍數。
   - 預設費率 NT$ 900/hr、加班倍數 1.5；可透過 `EditUserRateModal.tsx` 逐人調整。
   - 依工種（結構/建築/機電/施工）與月份（YYYY-MM）進行成本分佈彙整。
4. **排程偏差對比**：
   - 將任務 `estimatedHours` 預估基準與實際累計工時對比，呈現偏差時數與百分比。
5. **工時記錄清冊**：
   - 依日期排序的工時明細表，支援依工種與人員篩選，可刪除單筆紀錄。
6. **導航位置**：
   - Sidebar 在成員名冊與分隔線之間新增「工時管理 [06]」按鈕（Sidebar.tsx）；Header 新增 Tab `[04] 工時管理 (WORK HOURS)`。
